# XPENG CarPlay car button

`xpeng.svg` uses the XPENG symbol from the official website favicon:
https://a-cdn.xpeng.com/mall/public/favicon.svg
(retrieved 2026-10-13 from https://www.xpeng.com/).

The symbol is white on a black square, exported at 192 × 192 pixels to
`common/src/main/res/raw/ic_car_home.png`. Keep the PNG square and at or below
`AirPlayIconSizing.MAX_PIXELS` for the CarPlay connection handshake.

rights to the brand mark.
