# P7 设置目录

P7 取消独立概览页，默认进入“连接与启动”。不再显示独立 CarPlay 状态卡，连接方式卡片内保留“连接手机”主操作；已连接时该按钮用于打开 CarPlay。热点操作说明入口及重复说明不显示。热点弹窗内“确认”只暂存修改；主页面检测到修改后才显示“应用”，应用时写入设置但不打断当前会话。未应用的热点更改不会被连接操作自动保存。宽窗口保留侧栏目录；窄窗口使用统一目录选择行切换分类。其他分类返回“连接与启动”，旧概览状态自动迁移。

1. 连接与启动：使用统一选择行选择热点、Wi-Fi 或 USB，在同页下方显示该方式的配置；热点仅显示一条摘要行，点击弹窗配置名称、密码、安全性，确认后回到页面应用；Wi-Fi 名称与密码保留独立设置行，密码值始终掩码展示；随后显示自动启动和该方式的授权选项。
2. 画面与外观：外观、系统栏与全屏、画面大小/分辨率/帧率、实验性显示、视频兼容。
3. 声音与通话：音频输出、导航音量按键、音频兼容。
4. 导航与车况：定位及 GPS/DR、速度与挡位、电量与续航上报。
5. 按键与操作：CarPlay 手势、方向盘按键、车辆图标。
6. 歌词：悬浮歌词外观、来源、匹配、缓存及时间调整。
7. 仪表：仅独立地图投屏、自动启动、状态、启动/停止及车道条管理。
8. 诊断与排查：报告、认证、系统权限与连接帮助、启动修复、备份与恢复。方向比对、车辆信息读取与订阅已移除。
9. 关于：版本说明、项目及开源说明。语言跟随车机，不提供独立选择；旧的应用语言偏好及平台应用语言覆盖会清理。

P7 不再提供 Wi-Fi Direct 或仅本地热点作为连接方式。以前保存的 P7 Wi-Fi Direct 选择在读取时归入车机热点；无可用热点资料时须先保存资料才能连接。选择方式及保存资料不会中断当前会话，通过现有重连提示由用户决定生效时间。USB 方式不响应无线蓝牙重连自启，切回无线时保留原先的蓝牙自启偏好。

仪表参考 [OP-CarPlay 的第二路仪表设计](https://github.com/heavendoorx7/OP-CarPlay/blob/main/docs/IMPLEMENTATION.md)，保留当前独立 type 111 解码、受限本机 socket 和原车导航图像接口，歌词仅用于中控悬浮层。仪表选项已归入 `InstrumentMapSettings`；保留原有偏好存储及迁移，不重置已保存的地图设置。

图标使用 Lucide Android 矢量适配，来源与许可见 THIRD_PARTY_NOTICES.md。连接方式、名称、密码和安全性均使用共享设置行样式，尺寸与间距使用共享 dp 常量。

仅 Debug 构建允许在 Activity Intent 中附加 `preview_p7_settings=true`，用于普通 Android 模拟器预览 P7 设置。它只改变页面组成，不改变真实车型识别或授权仪表/热点硬件接口。Release 构建忽略该参数。

验证按 AGENTS.md 仅执行 `:mobile:assembleDebug`，视觉效果由用户检查。模拟器展示不能验证实车热点、iPhone CarPlay 或仪表地图输出。

设置是 CarPlay 的辅助页面：顶部不放车机主页按钮；宽窗口侧栏底部固定“退出”，窄窗口在标题栏提供同一操作。“退出”关闭设置并返回 CarPlay，不停止会话、不自动应用热点草稿。设置根页面的系统返回采用同一行为；车机桌面入口留在 CarPlay 的 XPENG 图标。

连接等待页跟随车机语言显示“连接中”，保留全屏 CarPlay 标识及轻量进度动画。返回设置使用共享按钮样式，宽屏至少 80dp 高、200dp 宽，窄窗口至少 64dp 高，并预留实际按钮高度避免覆盖中间内容。

连接等待页使用独立 InterfaceSize 上下文，遵循与设置页相同的界面比例，不修改 CarPlay 视频或触控密度。标题独立居中，动画隐藏时不保留其位置；手动待机显示 CarPlay，认证失败显示“无法连接”，开始连接才显示“连接中”。
