# 受限车机的 XPlay 操作

此定制版不从主应用打开 Android 系统设置、车机相册、系统文件选择器、分享面板或 APK 安装器。返回车机主页保留。Android 自身的权限请求和 VPN 授权仍按连接流程处理；已获授权时不会因此重复要求授权。

- **权限状态**：设置 → 连接 → 权限与连接帮助，选择“权限状态”。页面读取当前系统授权，不以“没有提示过”推断权限。特殊权限也会显示；缺失时需从车机自己的入口处理。
- **蓝牙和网络**：使用应用内操作说明，从车机主页手动配对、开启热点或连接 Wi-Fi，再返回 XPlay。选择已配对 iPhone、保存热点名称密码、连接模式和原有自动连接行为保留。
- **车辆图片**：设置 → 车辆 → 车辆按钮，选择“从手机上传图片”；CarPlay 内也提供同一入口。手机和车机须在同一可互访网络。扫描二维码或输入显示的地址和验证码，在手机选择图片。上传后在车机内部裁剪并保存；取消裁剪不替换已保存的图标。原有恢复默认图标功能保留。
- 图片通过临时本地 HTTP 入口传输，不上传互联网。每次使用新令牌，验证码受失败次数限制。手机端缩小图片并转为 JPEG，服务器限制请求大小并检查图片尺寸。关闭弹窗、离开活动或超时后停止服务。临时图片在完成/取消裁剪后删除，遗留缓存在后续上传时清理。
- **报告**：保留直接保存、应用内查看和手机下载。没有公共存储权限时使用应用存储回退，不调用文件选择器。原分享入口改为“在手机上获取报告”。
- **更新**：保留下载和校验。下载后查看“手动安装说明”，从车机支持的文件管理器或安装工具安装。无法生成可访问副本时，提示在手机/电脑下载 APK，再通过车机支持的方式安装。

本次交付只编译安装包，不截图、不执行自动化测试。手机浏览器上传、真实车机权限状态、裁剪及连接行为由用户验证。独立的 samples/home 桌面示例不属于主应用适配范围。
